Facebook Clone Website
A front-end web development project aimed at replicating the core user interface and basic functionalities of Facebook. This project was built as a practice exercise to strengthen skills in modern web development, focusing on responsive design, layout structures, and component-based architecture.

📖 About The Project
This repository contains the source code for a Facebook clone. The primary goal of this project was to understand how complex social media layouts are structured. It includes the main news feed, sidebar navigation, and user profile elements.

Whether you are a beginner looking to understand UI layouts or a developer checking out different styling techniques, this project serves as a great reference for building responsive, card-based web layouts.

✨ Key Features
Responsive Layout: Fully responsive design that adapts to desktop, tablet, and mobile screens.

News Feed UI: A visually accurate recreation of the main scrolling feed with post cards (placeholder images and text).

Navigation Bars: Fixed top navigation bar and sidebars for easy access to different sections (like Friends, Groups, and Marketplace).

Modern Styling: Utilizes modern CSS techniques (Flexbox/Grid) to achieve the exact spacing and alignment seen on the original platform.

Clean Code Structure: Organized HTML and CSS for readability and future scalability.

🛠️ Tech Stack
This project was built purely using front-end technologies:

HTML5: For the semantic structure of the web pages.

CSS3: For styling, animations, and layout (Flexbox/Grid).

JavaScript (Optional - if you added any): For basic interactive elements like dropdowns or toggling dark mode.

🚀 Getting Started
To get a local copy up and running, follow these simple steps.

Prerequisites
You only need a modern web browser (Chrome, Firefox, Edge, Safari) to view this project. No database or server is required.

Installation
Clone the repository:

bash
git clone https://github.com/ROHAN-A864/fb-clone-website.git
Navigate into the project directory:

bash
cd fb-clone-website
Open the project:
Simply double-click the index.html file to open it in your browser, or use a live server extension (like Live Server in VS Code) for a better development experience.
